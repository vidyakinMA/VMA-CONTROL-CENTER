# VMA Control Center (Vidyakin Makar Alexandrovich)

**VMA Control Center** — это портативный программный комплекс для операционной системы Windows, разработанный на языках **Batch** и **PowerShell**. 

Софт представляет собой единый лаунчер с удобным меню, который объединяет в себе набор системных утилит и инструментов для развлечений. Проект разрабатывался с упором на гибридную архитектуру: Batch отвечает за интерфейс и навигацию, а PowerShell используется для сложных системных вызовов, криптографии и работы с медиа.

## 🚀 Основные возможности

В состав комплекса входят следующие модули:

### 🛠 Системные утилиты
*   **SystemInfo** — подробный информатор о железе ПК (процессор, ОЗУ, видеокарта, диски, сеть).
*   **PortScanner** — анализатор сетевых портов с цветовой индикацией подозрительных подключений.
*   **PingTest** — тестер интернета с вычислением среднего пинга, оценкой качества в процентах и наглядным вердиктом.
*   **BackupPro** — машина резервного копирования файлов (поддерживает создание бэкапов по датам и выбор диска).
*   **PasswordSystem** — генератор криптографически стойких паролей с выбором длины и наборов символов.
*   **FileOrganizer** — умный сортировщик файлов по расширениям (раскладывает мусор по папкам).
*   **StartupManager** — менеджер автозагрузки (позволяет отключать лишние программы из реестра).

### 🎮 Развлечения
*   **Steam Client** — сканер библиотеки Steam, который находит установленные игры на всех дисках и запускает их.
*   **Music Player** — встроенный музыкальный центр, воспроизводящий аудиофайлы в формате `.wav` из папки с лаунчером.

## ⚙️ Установка и запуск

1. Скачайте архив с проектом.
2. Распакуйте его в любую удобную папку (желательно на диск, где есть место).
3. Запустите файл `VMA_CONTROL_CENTER.bat`.
4. Выберите нужный раздел в меню.

*Примечание: Для работы музыкального плеера в папке должна присутствовать папка "Музыка для клиента" с файлами `.wav`.*

## 🛡 Безопасность

Проект **не требует** установки стороннего ПО (кроме встроенных средств Windows). Все скрипты написаны открыто и не содержат вредоносного кода. Софт является портативным — его можно запускать с флешки на любом компьютере.
