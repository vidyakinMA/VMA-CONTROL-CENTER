# VMA-CONTROL-CENTER
Портативный программный комплекс для Windows на Batch и PowerShell. Включает системные утилиты (диагностика, сеть, бэкапы, пароли) и развлекательный блок (Steam-клиент, аудиоплеер). Разработано Видякиным М.А.
